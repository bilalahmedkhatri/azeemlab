## **🔍 Agency Website Audit Checklist**

To ensure a structured and detailed review, I will analyze each page across four critical dimensions: **Strategy & Content**, **Design & UX**, **Proof & Credibility**, and **Conversion**.

### **1\. Home Page Audit (The First Impression)**

| Dimension | Question | Analysis (Yes/No/Partial & Notes) |
| :---- | :---- | :---- |
| **Strategy & Content** | Is the **Unique Value Proposition (UVP)** clear in the hero section? (What you do, for whom, and why you're different). |  |
| **Design & UX** | Is the **Primary CTA** (Call-to-Action) above the fold and highly visible (using an accent color)? |  |
| **Proof & Credibility** | Is there strong **Social Proof** (client logos, awards, or key metrics) displayed early on? |  |
| **Conversion** | Does the page funnel users naturally to the **Portfolio/Services** pages? |  |

### **2\. Services Page Audit (The Offer)**

| Dimension | Question | Analysis (Yes/No/Partial & Notes) |
| :---- | :---- | :---- |
| **Strategy & Content** | Are the services explained in terms of **client benefit/result** rather than technical features? |  |
| **Design & UX** | Is the page easily scannable using clear headings, bullet points, or a card layout? |  |
| **Proof & Credibility** | Are relevant **client case studies** linked directly from each service description? |  |
| **Conversion** | Is there a clear, service-specific CTA (e.g., "Request a Quote for SEO")? |  |

### **3\. Portfolio / Case Studies Page Audit (The Evidence)**

| Dimension | Question | Analysis (Yes/No/Partial & Notes) |
| :---- | :---- | :---- |
| **Strategy & Content** | Does the content focus on the **Challenge, Solution, and Quantifiable Results**? |  |
| **Design & UX** | Is the layout visually rich (using large, high-quality images/mockups)? |  |
| **Proof & Credibility** | Are actual **client testimonials** included in the case study details? |  |
| **Conversion** | Does every case study end with a CTA to **start a similar project** or contact the agency? |  |

### **4\. About Us Page Audit (The Trust Builder)**

| Dimension | Question | Analysis (Yes/No/Partial & Notes) |
| :---- | :---- | :---- |
| **Strategy & Content** | Is the agency's **Core Philosophy/Process** clearly outlined? |  |
| **Design & UX** | Does the page use professional **team photography** to humanize the brand? |  |
| **Proof & Credibility** | Are the **Founders/Team Bios** professional but also convey personality? |  |
| **Conversion** | Is there a CTA inviting the visitor to **"Meet the Team"** or **"Schedule a Discovery Call"**? |  |

### **5\. Contact Page Audit (The Gateway)**

| Dimension | Question | Analysis (Yes/No/Partial & Notes) |
| :---- | :---- | :---- |
| **Strategy & Content** | Is the purpose of the form clear (e.g., "Start a Project," "General Inquiry")? |  |
| **Design & UX** | Is the **Contact Form** minimal (only asking for essential information)? |  |
| **Proof & Credibility** | Is the **Privacy/Security** of the submitted information mentioned (even briefly)? |  |
| **Conversion** | Are there **alternative contact methods** (email/phone) provided alongside the form? |  |
